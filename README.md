# 🏥 Healthcare Provider Analytics Dashboard

An interactive Power BI dashboard built to analyze healthcare operations, patient demographics, and hospital financial performance. The dashboard enables users to explore billing trends, treatment costs, insurance coverage, department performance, and diagnosis insights through dynamic and interactive visualizations.

---

## 📌 Overview

The Healthcare Provider Analytics Dashboard provides a centralized view of key healthcare metrics, helping users understand hospital performance and patient trends. Through interactive filters and dynamic visuals, the dashboard allows users to explore financial and operational data across different departments, procedures, diagnoses, cities, and states.

---

## 🛠️ Tech Stack

The dashboard was built using:

- **Power BI Desktop** – Interactive dashboard development and visualization.
- **Power Query** – Data cleaning and transformation (ETL).
- **DAX (Data Analysis Expressions)** – Calculated measures, KPIs, dynamic titles, and business logic.
- **Data Modeling** – Built relationships between multiple tables for efficient analysis.
- **Field Parameters** – Dynamic switching between City and State analysis.
- **Date Table** – Custom calendar table for time-based filtering.

---

## 📂 Data Source

**Dataset:** Healthcare Dataset by Prasad22 (Kaggle)

https://www.kaggle.com/datasets/prasad22/healthcare-dataset

The dataset contains synthetic healthcare records, including patient demographics, hospital information, billing amounts, insurance providers, diagnoses, medications, admission types, room charges, and visit dates.

## ✨ Features / Highlights

### Business Problem

Healthcare organizations generate large volumes of patient and financial data, making it difficult to monitor operational performance, treatment costs, and revenue trends efficiently. This dashboard consolidates key metrics into a single interactive report for easier analysis.

### Goal of the Dashboard

To develop an interactive healthcare analytics dashboard that enables users to analyze hospital billing, treatment costs, patient demographics, departmental performance, and diagnosis trends through intuitive visualizations and dynamic filtering.

### Walkthrough of Key Visuals

- **KPI Cards** provide a quick overview of Total Billing Amount, Treatment Cost, Medication Cost, Insurance Coverage, Out-of-Pocket Expenses, and Room Charges.
- **Dynamic Donut Chart** allows users to switch between **Top 5 Cities** and **State-wise** billing analysis using Field Parameters.
- **Procedure Analysis** compares billing generated across different medical procedures.
- **Department Analysis** highlights billing contribution by hospital department.
- **Diagnosis & Service Type** visual analyzes Emergency, Inpatient, and Outpatient cases across major diagnoses.
- **Interactive Slicers** allow filtering by Patient Race, Date, and geographic level for deeper analysis.

### Business Impact

The dashboard helps healthcare administrators monitor financial performance, identify high-performing departments and procedures, analyze regional billing patterns, and support data-driven operational and strategic decision-making.
